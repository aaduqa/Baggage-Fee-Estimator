Android app (Java) that estimates excess baggage fee for air travel.

- Inputs: baggage weight (kg), ticket class (Economy 20 kg / Business 40 kg), excess rate per kg (RM)
- Outputs: excess weight, excess baggage charge, total payable (charge + 8% service tax)
- Toolbar: Share (shares app URL) and About buttons
- About page: developer details, copyright, clickable GitHub URL

## Run
Open the folder in Android Studio, let Gradle sync, then Run on an emulator or device.
